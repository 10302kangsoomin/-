# 대한민국만세 홈페이지 (간소화 버전)

회원가입·일반 회원 로그인·회원 게시판·프로필·승인 기능을 제거했습니다. 누구나 역사 퀴즈에 참여할 수 있으며, 단일 담당자 로그인으로 페이지 콘텐츠를 편집하는 기본 구조를 포함합니다.

## 기능
- 한국어 / English / Tiếng Việt 선택과 브라우저에 언어 저장
- 로고와 대표 문구 중심의 홈 화면
- 7개 콘텐츠 메뉴 + 공개 역사 퀴즈 메뉴
- 퀴즈 정답/오답 피드백 및 캐릭터 이름 반응
- 단일 담당자 로그인, 콘텐츠 제목/본문/이미지 URL 편집
- 모바일 반응형

## 담당자 데모 계정
- 아이디: `01KSM`
- 비밀번호: `DHMQ!`

## 중요: 이 버전은 정적 데모입니다
GitHub Pages만 사용하는 정적 홈페이지에서는 이 로그인 정보와 관리 기능을 JavaScript에서 확인하기 때문에 보안상 보호되지 않습니다. 개발자 도구나 파일 내용을 열면 계정 정보가 보일 수 있고, 콘텐츠 변경은 로그인한 브라우저의 localStorage에 저장되어 해당 브라우저에서만 보입니다. 여러 방문자에게 공유되는 콘텐츠를 실제로 관리하거나 비밀 관리자 로그인으로 보호하려면 서버/백엔드(예: Firebase, Supabase, 별도 API)가 필요합니다. 이 데모의 관리자 비밀번호를 실제 비밀번호로 사용하지 마세요.

## 배포
1. GitHub 저장소 생성
2. `index.html`, `style.css`, `app.js`, `assets/` 업로드
3. 저장소 Settings → Pages → main branch / root로 배포 설정

## 파일 구성
- `index.html`: 구조
- `style.css`: 디자인/반응형
- `app.js`: 언어, 메뉴, 관리자 데모, 퀴즈, 로컬 콘텐츠 저장
- `assets/`: 로고 및 참고 캐릭터 이미지
